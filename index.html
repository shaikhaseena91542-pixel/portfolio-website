EchoGuard AI

AI-powered emergency safety web app.

Instead of relying only on a manual SOS button, EchoGuard AI is designed to detect possible emergency situations through voice-based signals and intelligent decision-making.

Features
  • Detects distress words like 'Help Me' and 'SOS'
  • Detects loud screams and distress voices
  • Calculates a Danger Score to reduce false alarms
  • Starts a smart SOS countdown with an 'I'm Safe' option
  • Retrieves the user's live GPS location
  • Opens Google Maps with the current location
  • Prepares an emergency SOS message for a family contact
  • Maintains alert history and emergency contact information
Tech Stack
HTML5 CSS3 JavaScript Geolocation API Web Speech API Local Storage Google Maps Integration
